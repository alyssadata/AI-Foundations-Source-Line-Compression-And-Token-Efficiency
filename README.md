## Purpose

This repository develops and makes testable a source-bound approach to reducing repeated context transmission in AI systems without treating lower token count as success when source, meaning, boundaries, or provenance are lost.

The central mechanism is **source-bound semantic compaction**: stable canonical terms act as reference keys only when they resolve through a fixed Source-line to locked canonical definitions and the runtime retrieves the exact controlling material required for the current task.

The proposed efficiency gain is **not yet established as an empirical result**. The repository defines the construct, architecture, hypotheses, comparison conditions, metrics, and claim boundaries required for controlled measurement.

## Research Question

Can a source-bound container reduce repeated prompt transmission by resolving stable canonical reference keys and retrieving only task-relevant controlling clauses **while preserving source attribution, meaning, boundaries, and provenance at an equal or higher rate than comparison conditions?**

---

## Evidence Boundary

A lower token count alone is not a pass.

The proposed mechanism must be evaluated separately for:

- token reduction;
- cost reduction;
- latency reduction;
- definition preservation;
- behavioral preservation; and
- provenance preservation.

Efficiency without source preservation is not a successful result under this framework.
